# calendarreport

Generates a daily Word (.docx) activity report whose dates, personnel section,
events table and wording are driven by that day's Google Calendar events, then
emails it.

## How it runs

This is **not** a standalone cron job. It runs inside a Claude session, because
the Google Calendar and Gmail access comes from Claude's built-in connectors.

```
Routine (daily, ~07:00 SGT)
  └─> Claude session
        ├─ Google Calendar connector → today's events
        ├─ build_report.py           → fills the .docx template
        └─ Gmail connector           → emails you the draft
```

You correct the names in the reply; Claude rebuilds and re-sends.

### Why not GitHub Actions

A GitHub Actions workflow cannot use Claude's connectors. Running this on CI
would require your own Google Cloud credentials (a service account key or an
OAuth refresh token stored as a repository secret) — a separate setup.
The scripts here are credential-free by design; the schedule lives in a Claude
Routine instead.

## Setup

```bash
cd calendarreport
python3 -m pip install -r requirements.txt
```

## Usage

```bash
# inspect what would be rendered, without writing a document
python3 src/build_report.py --events samples/events_sample.json \
    --date 2026-09-02 --dump-context

# build the document
python3 src/build_report.py --events samples/events_sample.json \
    --date 2026-09-02 --out output/report_2026-09-02.docx

# build with names you have confirmed
python3 src/build_report.py --events samples/events_sample.json \
    --date 2026-09-02 --names "Alice Tan,Bob Lim" --out output/report.docx
```

## Replacing the placeholder template

`templates/report_template.docx` is a throwaway generated by
`src/make_sample_template.py`, present only so the pipeline runs today.
**Replace it with your real template**, adding these placeholders where the
content should vary. The syntax is Jinja2 via
[docxtpl](https://docxtpl.readthedocs.io/).

### Single values

Type these directly into the document as ordinary text:

| Placeholder | Renders as |
|---|---|
| `{{ report_date }}` | `2 September 2026` |
| `{{ report_date_iso }}` | `2026-09-02` |
| `{{ day_of_week }}` | `Wednesday` |
| `{{ names_joined }}` | `Alice Tan, Bob Lim, Jasmine Chen` |
| `{{ event_count }}` | `4` |
| `{{ generated_at }}` | `2 September 2026, 20:56 +08` |
| `{{ intro }}` | the intro sentence chosen by the raised flags |
| `{{ closing }}` | the closing sentence chosen by the raised flags |

Any additional wording variants you add under `wording:` in
`config/mapping.yaml` become placeholders of the same name automatically.

### Names as a list

```
{% for n in names %}{{ n }}
{% endfor %}
```

### The events table

Build a table with a header row, then **three** more rows:

| Row | Contents |
|---|---|
| header | `Time`, `Event`, `Location`, `Category`, `Attendees` |
| 2 | `{%tr for e in events %}` in the first cell, rest empty |
| 3 | `{{ e.time }}`, `{{ e.title }}`, `{{ e.location }}`, `{{ e.category }}`, `{{ e.attendees }}` |
| 4 | `{%tr endfor %}` in the first cell, rest empty |

Rows 2 and 4 are deleted during rendering; row 3 repeats once per event.
Putting the `{%tr for %}` tag in the same row as the content **deletes that
content** — a real and easy mistake.

### Word gotcha

Word silently splits typed text into multiple internal runs (autocorrect,
spellcheck, a mid-word format change), which breaks a `{{ tag }}` in half and
makes it render as literal text. If a placeholder does not substitute, delete it
and retype it in one go, or paste it as unformatted text.

## Configuring the rules

`config/mapping.yaml` holds everything that decides how a calendar event affects
the document:

- `exclude` — event titles dropped entirely (regex, case-insensitive via `(?i)`)
- `rules` — title patterns → a `category` for the table, plus `flags`
- `default` — the category applied when no rule matches
- `wording` — the sentence variants, selected by flag
- `names` — which categories contribute attendee names, and who to filter out

The shipped values are **examples**, not your real process. Rewrite them.
